The four [Catppuccin](https://catppuccin.com) flavours as [napari](https://napari.org) themes: Latte (light), Frappé, Macchiato and Mocha.

## Installation

```bash
pip install napari-catppuccin
```

Then pick a theme under **Preferences → Appearance → Theme**.
